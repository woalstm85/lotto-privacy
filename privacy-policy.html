로또 픽커 개인정보처리방침

Lotto Picker Privacy Policy

최종 업데이트: 2025년 6월

📌 요약

로또 픽커는 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다. 모든 데이터는 사용자의 기기에만 저장됩니다.

1. 수집하는 정보

로또 픽커는 다음과 같이 최소한의 데이터만 기기 내부에 저장합니다. 별도의 회원가입이나 개인정보 입력이 필요하지 않습니다.

📋 추첨 기록 / 즐겨찾기 / 구매 내역
사용자가 생성한 로또 번호 기록. 기기 내 로컬 저장소에만 보관되며, 외부로 전송되지 않습니다.
⚙️ 앱 설정
다크모드, 효과음, 알림 여부, 고정수/제외수 필터 등 사용자 환경설정. 기기 내 로컬 저장소에 보관됩니다.

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 신원 식별 정보
  • 위치 정보 (GPS)
  • 기기 식별자 (IMEI, 광고 ID 등)
  • 앱 사용 패턴 / 분석 데이터
  • 기타 민감한 개인정보

3. 사용 권한 안내

권한 용도 선택/필수
📷 카메라 로또 티켓 QR 코드 스캔 (당첨 확인) 선택
🔔 알림 매주 토요일 로또 추첨 알림 (설정에서 직접 켤 때만 요청) 선택
🌐 인터넷 최신 로또 당첨번호 조회 (동행복권 웹사이트) 필수

카메라 및 알림 권한은 사용자가 해당 기능을 사용하려 할 때만 요청되며, 거부해도 핵심 기능(번호 생성)은 정상 작동합니다.

4. 외부 서비스

최신 로또 당첨번호를 확인하기 위해 동행복권 웹사이트(dhlottery.co.kr)에서 공개된 당첨번호 데이터를 조회합니다. 이 과정에서 사용자의 개인식별 정보는 전혀 전송되지 않으며, 단순 조회만 수행합니다.

  • 조회 대상: 동행복권 웹사이트 (dhlottery.co.kr)
  • 조회 내용: 회차별 당첨번호 (공개 정보)
  • 전송되는 개인정보: 없음

판매점/당첨점 찾기 기능은 동행복권 공식 웹사이트를 외부 브라우저로 열며, 해당 사이트의 개인정보처리방침이 적용됩니다.

5. 데이터 보관 및 삭제

모든 앱 데이터는 사용자 기기의 로컬 저장소에만 존재합니다.

  • 삭제 방법: 앱 내 설정 → 추첨 기록 전체 삭제
  • 완전 삭제: 기기에서 앱을 삭제하면 모든 데이터가 함께 제거됩니다.
  • 개발자는 사용자 데이터에 접근할 수 없습니다.

6. 면책 사항

로또 픽커는 통계적 분석을 제공하는 재미 목적 앱입니다. 번호 추천 알고리즘은 과거 데이터 기반의 확률 모델로, 당첨을 보장하지 않습니다. 로또는 완전한 독립 시행이므로 어떤 방법으로도 결과를 예측할 수 없습니다.

7. 방침 변경

본 개인정보처리방침이 변경될 경우, 이 페이지에 최신 내용을 반영하고 상단의 업데이트 날짜를 갱신합니다.
